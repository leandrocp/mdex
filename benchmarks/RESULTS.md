# Markdown benchmark results

Generated by [`benchmark.exs`](benchmark.exs) on 2026-11-01 14:10 EST (America/Toronto) at MDEx commit `430828b`.

- Machine: Intel(R) Xeon(R) Processor @ 2.60GHz, 2 logical CPUs, 3.8 GB RAM, Linux 6.1.158+ x86_64
- Elixir 1.20.5, Erlang/OTP 29 (erts 17.1.1, JIT), pandoc 2.17.1.1
- Benchee per row: 2 s warmup, 5 s run time, 1 s memory, 1 s reductions. Each library runs in its own BEAM.
- Every library ran 2 times, in separate rounds; each row reports the round with the lower median, so a burst of load on this shared VM doesn't decide a row.
- Before a row is benchmarked, one call runs on its own: a call over 60 s is a **timeout**, a call that raises or returns an error is an **error**.
- ips is calls per second (higher is better). Memory is what Benchee measures on the BEAM process heap, so it leaves out memory a NIF or an external program allocates.
